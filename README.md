# Digital Practice Hub

CHDPU AMALIYOT PLATFORMASI — PREMIUM UI/UX REDESIGN

Mavjud amaliyot.cspu.uz saytining UI/UX dizaynini to‘liq qayta ishlab chiq.

Bu oddiy universitet landing page bo‘lmasligi kerak. Natija premium digital university platform, zamonaviy EdTech/SaaS product va professional academic ecosystem hissini berishi kerak.

Konsept: "DIGITAL PRACTICE — CHDPU" (4+2 tizimi).
Dizayn tizimi: Linear, Vercel, Apple, Stripe uslubidagi premium akademik platforma. Ranglar: Primary Dark (#111827), Deep Indigo (#312E81), Accent Indigo (#6366F1), Purple (#8B5CF6), Background (#F8FAFC).
Barcha asosiy bo'limlar: Hero (4+2 interaktiv animatsiya, status kartalari), Amaliyot qidirish (talaba, maktab, tuman bo'yicha filterlar), Real-time statistika, Amaliyot jarayoni bosqichlari (4 bosqich), Ekosistema rollari (Talaba, Amaliyot rahbari, Fakultet, Amaliyot bo‘limi), Universitet vizual bo'limi, Kirish (Login) va Amaliyot Dashboard interfeysi.

Iltimos, ilova qilingan batafsil texnik topshiriqdagi barcha talablar asosida platformani to'liq yarat.
